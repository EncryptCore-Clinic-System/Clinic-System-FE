# Clinic System (Desktop App)

A Clinic Management desktop application using **C#** and **.NET Framework (WinForms)**.  
This project helps with managing clinic operations: doctor, receptionist, patients, and reporting.  

---

## 🛠 Features

- User authentication (login/logout)
- Patient management (add, update, delete)
- Generation of reports
- Export data to **Excel** and **PDF**
- Navigation UI with a panel/side bar

---

## 🔧 Technologies Used

| Component | Details |
|----------|---------|
| Language | C# |
| Framework | .NET Framework, WinForms |
| ORM | Entity Framework (MyContext) |
| Database | SQL Server (or your configured DB) |
| PDF Export Library | iTextSharp |
| Excel Export Library | ClosedXML (or Interop) |
| UI | WinForms with Panels for navigation & content |
